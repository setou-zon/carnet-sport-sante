# Carnet Sport Santé & Sport pour tous

Plateforme du MSJE (DGSL / DST) : carnets Sport Santé des participants (PDF A6, tableau de bord) et collecte Sport pour tous (fiches de présence, circuit Site → DPSJE → DRSJE → SSEC/DST).

Ce dépôt contient deux versions :

| Dossier | Version | Serveur |
|---|---|---|
| racine (`index.html`, `sw.js`…) | Version actuellement en ligne : https://setou-zon.github.io/carnet-sport-sante/ | Supabase |
| [`laravel/`](laravel/) | **Version Laravel**, à installer sur un serveur du ministère. Mêmes écrans, données hébergées au Burkina | Laravel 13 + MySQL |

Guide d'installation de la version Laravel : [`laravel/README.md`](laravel/README.md).

Aucune donnée de participant n'est stockée dans ce dépôt.
